# Combining bricks

Compute Flow bricks are reusable AI building blocks that can be composed into larger application
pipelines. Each brick is loaded from a manifest, configured with `BrickOptions`, set up once, and
then executed through the common brick runtime API.

For a runnable three-brick application, see
[Combining bricks to build an audio-to-audio translation pipeline](../examples/python/audio_to_audio_translation.md).

Applications should depend on the brick contract rather than a specific brick implementation:

- In C++, include `compute_flow/compute_flow.h` and link against the brick type libraries installed
  by the Compute Flow brick manager.
- In Python, import `compute_flow_py` and use the same runtime lifecycle exposed by the C++ API.

## Connect two bricks

Connect bricks by passing the output tensor from one brick into the input tensor of another. The
examples below pass text generated by a language model brick to a text-to-speech brick. They assume
that each brick produces its complete output in one call to `run()`.

### Python

```python
import compute_flow_py as cf

text_manifest = cf.load_manifest("<path-to-lm-text-manifest>")
text_brick = cf.load_brick(text_manifest)
text_brick.setup(text_manifest)

tts_manifest = cf.load_manifest("<path-to-tts-manifest>")
tts_brick = cf.load_brick(tts_manifest)
tts_brick.setup(tts_manifest)

text_output = text_brick.run({"text_prompt": "Write a short greeting."})

# Connect the text brick's output to the text-to-speech brick's input.
tts_input = {"text_prompt": text_output["text"]}
speech_output = tts_brick.run(tts_input)
```

### C++

```cpp
#include <compute_flow/compute_flow.h>

#include <string>

using namespace compute_flow;

auto text_manifest = bricks::load_manifest("<path-to-lm-text-manifest>");
auto text_brick = bricks::load_brick(text_manifest);
text_brick->setup(text_manifest);

auto tts_manifest = bricks::load_manifest("<path-to-tts-manifest>");
auto tts_brick = bricks::load_brick(tts_manifest);
tts_brick->setup(tts_manifest);

std::string prompt = "Write a short greeting.";
TensorDict text_input;
text_input.declare_tensor("text_prompt");
text_input["text_prompt"].data = prompt.data();
text_input["text_prompt"].format.dt = DataType::String;
text_input["text_prompt"].format.shape = {static_cast<int64_t>(prompt.size())};

auto text_output = text_brick->run(text_input);

// Connect the text brick's output to the text-to-speech brick's input.
TensorDict tts_input;
tts_input.declare_tensor("text_prompt");
tts_input["text_prompt"] = text_output["text"];
auto speech_output = tts_brick->run(tts_input);
```

The connection is the assignment of the `text` output to the TTS `text_prompt` input. Each brick
keeps its own input and output names, so the application maps the tensors between them.

## Support streaming-capable bricks

It is recommended to use `is_generation_complete()` so the application also works with brick
variants that produce output over multiple calls to `run()`. Replace the inference part of the
previous example with:

### Python

```python
text_input = {"text_prompt": "Write a short greeting."}
generated_text = ""

while not text_brick.is_generation_complete():
    text_output = text_brick.run(text_input)
    generated_text += text_output["text"]
text_brick.reset_states()

tts_input = {"text_prompt": generated_text}

while not tts_brick.is_generation_complete():
    speech_output = tts_brick.run(tts_input)
    # Consume each speech output chunk here.
tts_brick.reset_states()
```

### C++

```cpp
std::string generated_text;

while (!text_brick->is_generation_complete()) {
    auto text_output = text_brick->run(text_input);
    const auto& chunk = text_output["text"];
    generated_text.append(
        static_cast<const char*>(chunk.data),
        static_cast<size_t>(chunk.format.get_nbytes())
    );
}
text_brick->reset_states();

TensorDict tts_input;
tts_input.declare_tensor("text_prompt");
tts_input["text_prompt"].data = generated_text.data();
tts_input["text_prompt"].format.dt = DataType::String;
tts_input["text_prompt"].format.shape = {
    static_cast<int64_t>(generated_text.size())
};

while (!tts_brick->is_generation_complete()) {
    auto speech_output = tts_brick->run(tts_input);
    // Consume each speech output chunk here.
}
tts_brick->reset_states();
```
